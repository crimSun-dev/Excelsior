Visualize renders the locked direction as thumbnails before the chapter is planned at full length, when image generation is available. It answers "which world and which composition" with pictures instead of adjectives.

## What to render

Three thumbnail options of the chapter's first spread (or the memorable page), each a different composition inside the same locked world: same paper, line and lettering voices; different staging (where the dominant panel sits, which technique the page uses).

## The shared frame

- Rough, matte, deliberately unfinished thumbnails: loose figures, blocked values, panel borders, balloon shapes with greeked text. No finished rendering; a thumbnail that looks more finished than the others has broken the comparison, not won it.
- Same trim and reading direction for all three; webtoon thumbnails are tall strips at the platform width ratio.
- The only legible text is the series title and one real line from the script; every other balloon is greeked.
- No real artists' characters or recognisable copyrighted designs; the series' own cast only, from its model sheets or descriptions.

## Producing them

Build the prompt from the plan's panel prompts plus the world block of the direction contract. Generate in the order the user reads: option A, B, C. When subagents can run in parallel, one agent per thumbnail. With no image generation, present the three as proof-sheet geometry with shot and value notes; that is complete, not lesser.

## Decide

Put the three before the user (structured question tool, thumbnails attached). The chosen thumbnail seeds the plan's first pages; the others are discarded.
